# Deploying DeepSeek-R1-Distill-Qwen-7B Inference Service on Kunpeng Cloud

## Introduction
This guide demonstrates how to deploy the DeepSeek-R1-Distill-Qwen-7B model using the vLLM framework on a Kunpeng Cloud server (aarch64 architecture) running Huawei Cloud Euler OS (HCE). The deployment provides an OpenAI-compatible HTTP API interface.
<br>With Dify installed, users can leverage Dify to configure and deploy model services for low-code AI Agent development.
