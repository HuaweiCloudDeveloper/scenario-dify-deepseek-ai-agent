# Deployment of DeepSeek-R1-Distill-Qwen-7B and Dify on Kunpeng Cloud for Private AI Agent Development

## Introduction
On the Kunpeng Cloud, the DeepSeek-R1-Distill-Qwen-7B inference service is deployed using the vLLM framework on Huawei Cloud Euler OS (referred to as HCE) or Ubuntu 22.04. <br>

By installing Dify, users can:
- Develop low-code AI Agents through Dify's configuration of the deployed model service.
- Deploy and run AI Agent applications via Dify.

## Applicable Scenarios
DeepSeek-R1 is a high-performance AI inference model that focuses on reasoning tasks related to mathematics, coding, and natural language. Combined with the Dify platform, it can quickly create a personalized private AI assistant.
<br>
The main application scenarios include:
- Natural Language Processing (NLP): Capable of understanding and generating natural language text, suitable for tasks such as conversation, translation, and summarization.
- Text Generation: Capable of generating coherent and logically clear text, suitable for content creation, story writing, and other tasks.
- Question-Answering Systems: Capable of answering user questions, suitable for customer service and knowledge base queries.
- Sentiment Analysis: Capable of analyzing the sentiment orientation in text, suitable for market research and public opinion monitoring.
- Text Classification: Capable of classifying text, suitable for spam filtering and news categorization.
- Information Extraction: Capable of extracting key information from text, suitable for data mining and knowledge graph construction.
